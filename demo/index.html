The theme is one static sky plus one live fire field. The sky is generated once at load, dithered against banding, and never brightens; only the flame layer reacts when an agent starts working.

  • Idle keeps a low ember line along the bottom edge.
  • Thinking raises separate flame fronts and warms the floating chat frames.
  • The reading veil sits above the flames, so transcript text keeps its contrast.
theme.css 
/* the only thing that reacts to agent state */
body[data-ds-nebula-theme][data-ds-nebula-think='on'] .dsnb-fire {
  opacity: 0.95;
  filter: blur(5px) saturate(1.08);
}

Everything is scoped to a single body attribute, so disabling the plugin removes every layer and token override without touching the base palette.
